# - **Project Title:** 
BarangayConnect

# - **Description:** 
A responsive web portal that helps residents access barangay services online. Residents can review available services, submit requests, and check request status using a reference number.

# - **Features:**
  - View barangay services, including clearance, residency certificates, business permits, indigency certificates, and complaint blotter reports.
  - Register an account and log in.
  - Check for an existing request before submitting a new one.
  - Submit service requests and receive a reference number.
  - Track a request and view its current status.
  - Use the interface on mobile and desktop, with light and dark themes.
  - View barangay contact details and an embedded map.

# - **Technologies:**
  - HTML, CSS, and vanilla JavaScript
  - Node.js and Express
  - MySQL-compatible database (MySQL or TiDB Cloud) with `mysql2`
  - `bcryptjs` for password hashing
  - Google Maps embed for the location map
  - Render for web hosting
